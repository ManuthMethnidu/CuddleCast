# CuddleCast

## What This Is
CuddleCast is a high-performance web streaming application combining modern Stremio-like movie/series discovery, interactive 3D Radio Atlas, 24/7 Live TV broadcasts, and a dedicated Live Sports & Formula 1 Center. It is built using React, Vite, Tailwind CSS, and Google Material Design 3 Expressive (`@material/web`).

## Core Value
High-speed, distraction-free streaming and real-time live sports/radio with zero clutter and a fluid Material 3 Expressive interface.

## Requirements

### Validated
- [x] Stremio / Cinemeta movie and TV catalog browsing
- [x] Material 3 Expressive design system integration with dark mode tokens
- [x] Interactive 3D Radio Atlas with global station playback
- [x] 24/7 Live TV streams and YouTube Live news aggregation
- [x] Formula 1 Grand Prix schedule, standings, and verified motorsport streams

### Active
- [ ] Phase 1: Real F1 free streaming feeds, multi-sport live events, stream redundancy/failover, and race telemetry integration

### Out of Scope
- Paid subscriptions / paywalled stream integrations — focusing exclusively on free, legal, and publicly accessible web feeds
- Discord/Donate popups — keeping interface clean and clutter-free
