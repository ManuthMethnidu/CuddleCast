# Requirements: CuddleCast

**Defined:** 2026-10-27
**Core Value:** High-speed, distraction-free streaming and real-time live sports/radio with zero clutter and a fluid Material 3 Expressive interface.

## Phase 1 Requirements

### Real F1 & Sports Streaming

- [x] **REQ-01**: Users can watch live Formula 1 Grand Prix sessions and 24/7 motorsport channels with automatic stream failover.
- [x] **REQ-02**: Live timing, lap gaps, tire compounds, and session status reflect current or upcoming race weekends via OpenF1 and Jolpica APIs with track simulator fallback.
- [x] **REQ-03**: Multi-sport live feeds (Champions League, Premier League, NBA, UFC) stream smoothly via direct HLS / embed fallbacks.
- [x] **REQ-04**: Material 3 Expressive UI provides high-contrast controls, circuit telemetry cards, and multi-view/pip capabilities.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Paid/Paywalled streaming subscriptions | Focusing exclusively on free, legal, and publicly accessible web feeds |
| Discord and Donate popups | Keeping interface clean, uncluttered, and distraction-free |
| Betting / Gambling integrations | Outside scope of core sports viewing experience |
