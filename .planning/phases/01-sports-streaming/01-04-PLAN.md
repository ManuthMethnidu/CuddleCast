## Threat Model
<threat_model>
### Security Capabilities
- **T-04-01 (Notification Permission Abuse / Browser Denial):** Rapid or spammy permission requests triggering browser security penalties.
  * *Mitigation:* Explicit user gesture gate (`onClick` on "Enable Race Alerts") before calling `Notification.requestPermission()`. Persist user preference in `localStorage`. Never call `requestPermission()` unconditionally on page mount.
- **T-04-02 (Web Audio Context Auto-Play Violations):** Browsers suspending un-gestured `AudioContext`, throwing unhandled promise rejections.
  * *Mitigation:* AudioContext initialized only after user gesture or suspended state safely handled (`ctx.state === 'suspended' ? ctx.resume() : null`).
- **T-04-03 (Unvalidated Stream URLs in Match Cards):** Arbitrary URLs passed into video player or iframe launcher.
  * *Mitigation:* Validate all stream URLs with `URL` constructor and restrict schemes strictly to `https:`.
</threat_model>
