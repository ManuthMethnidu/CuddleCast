## Visual Hierarchy & Focal Points

### Primary Visual Anchor
The **16:9 Theater Mode Player Viewport** at the top center of the Command Center acts as the primary focal point:
- **During Live Sessions:** The active broadcast stream (or Driver Onboard camera) anchors the screen, highlighted with high-contrast glassmorphic beveling, an active channel indicator, and an ambient accent drop glow.
- **During Off-Track Periods:** The viewport displays the official circuit hero banner, dynamic track telemetry simulator deltas, and live session countdown timer digits.

### Secondary Visual Anchors
1. **Channel Selector Pill Bar:** Positioned directly beneath the theater canvas for immediate 1-click channel switches (Sky Sports F1 ENG, Sky Sports F1 IT, Onboards).
2. **Multiview Command Center Drawer:** 3-tab collapsible side panel housing Driver Onboard Cam, Live Timing Leaderboard, or Twitch Watch Party Chat.

### Tertiary Visual Anchors
- 2026 Grand Prix weekend session schedule timetable cards and World Championship driver/constructor standings.

### Accessible Action Labels
Every icon-only control carries an explicit `aria-label` and matching `title` attribute for screen readers:
- Picture-in-Picture trigger: `aria-label="Open Picture-in-Picture"`
- Fullscreen trigger: `aria-label="Toggle Fullscreen Mode"`
- Multiview drawer collapse: `aria-label="Collapse Multiview Panel"`
- Audio mute button: `aria-label="Toggle Audio Mute"`
- Notification bell: `aria-label="Manage Race Reminders"`
- Reconnect stream action: `aria-label="Retry Stream Connection"`

## Layout Anatomy & Responsive Breakpoints

### Responsive Breakpoints
- **Mobile (`< 640px`):** Single-column stacked layout. The 16:9 theater player spans full viewport width. Channel switcher pills render as a horizontally swipeable pill strip. The Multiview Command Center drawer renders beneath the video player as an expandable accordion bottom sheet.
- **Tablet (`640px` - `1023px`):** Single-column layout with centered 16:9 player container. Channel selector bar is centered below the canvas. Multiview panel renders below the player as a tabbed container with 3 segmented views.
- **Desktop (`>= 1024px`):** 2-column Command Center layout:
  - **Left Column (70%):** 16:9 Theater Viewport + floating channel switcher pill bar + real-time telemetry ribbon.
  - **Right Column (30%):** Collapsible Multiview Drawer (Tab 1: Driver Onboard Cam, Tab 2: Live Timing Leaderboard, Tab 3: Twitch Darkpopout Chat).
- **Ultrawide (`>= 1536px`):** Max container width clamped to `1560px` with centered margins, supporting side-by-side dual video playback (Main Feed + Onboard Cam).

## Interaction States & Edge Cases

### 1. Stream Buffering & Loading
- Center-aligned `<md-circular-progress indeterminate>` displayed over a darkened 16:9 canvas (`rgba(0, 0, 0, 0.65)`).
- Quality indicator badge in player corner displays pulsating "Buffering..." text.
- Player viewport aspect ratio is locked to 16:9 using CSS `aspect-ratio: 16 / 9` to guarantee zero layout shift (CLS 0.0).

### 2. Stream Failover & Exponential Backoff State Machine (D-01, D-03)
When an upstream HLS stream encounters a network or manifest parsing error:
- **Attempt 1 (1,000ms delay):** Status banner displays "Reconnecting (Attempt 1 of 3)...".
- **Attempt 2 (2,500ms delay):** Status banner displays "Reconnecting (Attempt 2 of 3)...".
- **Attempt 3 (5,000ms delay):** Status banner displays "Reconnecting (Attempt 3 of 3)...".
- **Exhausted Retries (Failover):** Player transitions to state `EMBED_FALLBACK`, mounting a secure sandboxed `<iframe>` (`sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox"` and `allow="autoplay; fullscreen"`).
- Toast banner displays: "Primary Stream Offline: Switched to Sandboxed Embed Mirror 1."

### 3. Session Countdown Timer & State Transitions (D-03, D-09)
- When `session.state === 'upcoming'`:
  - Countdown timer calculates difference: $\Delta t = T_{\text{start}} - T_{\text{now}}$.
  - If $\Delta t > 24 \text{ hours}$: Formats as `DDd HHh MMm`.
  - If $\Delta t \le 24 \text{ hours}$: Formats as `HH:MM:SS` updating every 1 second.
  - Dual time readout displays User Local Time (`Intl.DateTimeFormat`) and Circuit Local Time.
- When $\Delta t \le 0$:
  - Session state switches automatically from `upcoming` to `live`.
  - Countdown changes to a pulsating red "LIVE NOW" badge.
  - Channel selector pills enable 1-click stream switching.

### 4. Interrupted Coverage & Red Flag Banner (D-03)
- If broadcaster pauses transmission or race control throws a red flag, an amber banner docks across the top of the theater canvas:
  "Broadcaster Feed Interrupted: Upstream broadcast temporarily paused. Standing by for live feed restoration..."

### 5. Picture-in-Picture (PiP) Capabilities (D-06)
- **Direct HLS Feed:** The PiP icon button is enabled. Clicking calls `HTMLVideoElement.requestPictureInPicture()`, detaching the video into a native floating window.
- **Sandboxed Embed Mirror:** PiP is not supported by third-party iframes. The PiP button is rendered in a disabled state with tooltip: "Picture-in-Picture requires direct HLS stream. Switch to HLS feed for floating player."

### 6. Web Notification Alerts & Permissions (D-09)
- Notification banner rendered on upcoming session cards with primary action "Enable Race Alerts".
- On click, triggers `Notification.requestPermission()`.
- Alerts triggered at:
  - **T-15 Minutes:** "🏎️ Formula 1: {Session Name} starts in 15 minutes! Tune in now."
  - **Lights Out (T-0):** "🟢 Lights Out! {Session Name} is now LIVE."
- If notification permissions are blocked in browser, system falls back to an in-app visual toast and audio chime.
