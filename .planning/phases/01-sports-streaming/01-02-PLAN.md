# Plan 01-02: Hybrid WatchItBetter Streaming Pipeline, Exponential Failover (1s, 2.5s, 5s), Sandboxed Iframe Player, and HTML5 Native Picture-in-Picture

<objective>
Implements D-01: Hybrid WatchItBetter Streaming Model, D-02: Sandboxed Embed Security, and D-03: Live Channel Availability State. Build a resilient dual-mode streaming pipeline supporting direct low-latency HLS (.m3u8) feeds, exponential backoff failover, and strict sandboxed iframe embeds.
</objective>

## Plan Overview
Implement the robust hybrid streaming engine modeled after WatchItBetter. It orchestrates high-bitrate direct HLS playback (`.m3u8`) with low latency mode and HTML5 native Picture-in-Picture (PiP). When an upstream live feed drops or network errors occur, an automated exponential failover state machine (retrying at 1s, 2.5s, 5s) seamlessly transitions to a secure, sandboxed embed mirror without breaking user immersion or allowing intrusive ad redirects.

## Threat Model
<threat_model>
### Security Capabilities
- **T-02-01 (Top-Navigation Ad Hijacking):** Malicious ad scripts in third-party embed streams attempting to hijack `window.top.location` and redirect users away from CuddleCast to phishing/gambling sites.
  * *Mitigation:* Strict sandbox definition: `sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox"`. Crucially, NEVER include `allow-top-navigation` or `allow-top-navigation-by-user-activation`.
- **T-02-02 (Origin Leakage via Referrer):** Embed iframes leaking internal query parameters or tokens to external stream servers.
  * *Mitigation:* Enforce `referrerPolicy="strict-origin-when-cross-origin"` on all embed iframes.
- **T-02-03 (Unbounded Reconnect Loops):** Downstream client endlessly bombarding failing HLS endpoints, causing client CPU spikes and CDN rate-limits.
  * *Mitigation:* Strict retry limit capped at 3 attempts with exponential backoff (1s, 2.5s, 5s), then permanently transitions to `EMBED_FALLBACK`.
</threat_model>
