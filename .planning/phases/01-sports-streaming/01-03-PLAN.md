## Threat Model
<threat_model>
### Security Capabilities
- **T-03-01 (Chat Iframe Cross-Origin Exploits):** Embedded Twitch chat iframe attempting top-level navigation, unauthorized cookie access, or clickjacking.
  * *Mitigation:* Safe parent parameter encoding (`encodeURIComponent(window.location.hostname)`), strict sandboxing (`sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox"`), and zero top-navigation privileges.
- **T-03-02 (Memory Leaks in High-Frequency Subscriber Loops):** Telemetry HUD and Leaderboard subscribing to 1Hz/3.7Hz streams without unhooking on component unmount or drawer tab switch.
  * *Mitigation:* All simulator and OpenF1 subscriptions must return unsubscribe functions consumed in React `useEffect` cleanups.
- **T-03-03 (DOM Injection via Driver Acronyms or Team Names):** Untrusted strings from API rendering unescaped into DOM.
  * *Mitigation:* Pure React text node rendering (no `dangerouslySetInnerHTML`) preventing script injection.
</threat_model>
